# Guided interviews and form handoff

[AI prompt contract](ai-prompts.md) is the authoritative definition of every copied prompt. This guide describes using and manually reviewing that workflow.

Copy the tab's AI guided interview into the project's existing AI conversation. It contains the full current-tab form structure, eligible records, nested children, and current answers so the AI can account for every applicable item. Earlier connected-project evidence stays outside the interview; use reliable prior conversation history or project memory for those facts. The AI silently checks what is already known, makes reasonable low-risk inferences, and asks only short questions about consequential unresolved facts. If existing information already supports the form, it skips the interview questions entirely. Coverage is internal, not a field-by-field recap; the handoff names only necessary corrections, additions and import scopes.

Paste the requested section, parent-group, record, or nested-item prompt into the same conversation. Ordinary form prompts return exactly one `dsrs-form` v1 JSON response with supported values for the selected scope. Existing record IDs and nested IDs must match, while agreed new records omit IDs. Unsupported values use null/omission and meaningful gaps go into `needsInformation`. In Dynamic SRS, open **Paste AI response**, paste the JSON, choose **Validate JSON**, review the planned updates/additions, then explicitly choose **Apply to workspace**. Pasting alone never changes data; the result is merge-only. The app opens the panel when a structured prompt is copied. Diagrams use their separate `dsrs-diagram` importer, and Notes still uses its audited manual-entry editor.

If the inventory changes, copy a fresh tab prompt. A previous copied prompt cannot know records added later.

## Manual review — not run

1. Copy a populated Use Cases tab with 15 entries, blank required values, actor groups, and relationships. Confirm all IDs, current answers, child contracts, choices and conditions appear without truncation. The AI should silently account for every entry, ask only about genuinely unsupported consequential gaps, and avoid recapping unchanged records.
2. Repeat with an empty catalog and a newly added blank record. Expect a complete record template and supported discovery of additions, without fabricated entries or new IDs. Copy a fresh prompt after adding an entry.
3. Copy a whole-section prompt, one parent group's prompt, one record prompt, and one nested-item prompt from the same tab. Confirm the requested outputs match their scopes, include exact labels and child formats, and return complete supported values without follow-up questions or an update-only response.
4. Exercise nested note references, the optional note change explanation, annual CBA values, multiple record links, Detailed Descriptions' conditional flows, and quality/interface applicability. Confirm child paths and conditional contracts are explicit; app-created edit history is excluded, and optional, read-only, automatic, retired, and ineligible fields are handled consistently.
5. Compare an interview with the subsequent form prompt. The interview includes complete current-tab answers and excludes earlier-source excerpts/calculated financial enrichment. Form prompts retain complete selected evidence, exact reference choices, and CBA/FSA calculated results. Neither includes diagram payloads or tooltip text.
6. Try a genuinely unsupported required fact and an unavailable reference: expect one precise interview question about the missing fact and a brief **Needs information** entry rather than guessed data in subsequent form JSON. Repeat with fully supported current answers: expect zero questions and a direct handoff. Existing saved values remain untouched until explicitly changed.
7. Review copied prompts from CR, SR, CBA, FSA, all implemented SRS stages (including Phase 5), Effort Breakdown and General Notes. Confirm task guidance follows the shared two-job contract, including actor/goal editing. Empty optional collections must not force fabricated records. Check that imported narrative/Markdown fields contain compact, nonduplicative values with necessary acceptance details, not essays.

Diagram generation is a dedicated semantic handoff rather than a formatted metadata answer. A repeatable diagram section uses one fenced `dsrs-diagrams` batch preserving the interview's agreed ordered figure partitions; an individual figure uses one fenced `dsrs-diagram` graph and replaces only that file. Follow [AI-generated diagrams](ai-diagrams.md) for selected evidence, atomic section import, individual replacement and shared rendering checks. Ordinary interviews and metadata scopes must still exclude stored file contents.
